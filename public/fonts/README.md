# Bundled typefaces

Geist and Source Serif 4 are self-hosted Latin variable webfonts from Google Fonts, downloaded October 17, 2026. Browsers make no requests to a font provider. The adjacent OFL files preserve the respective licenses.

- Geist: https://github.com/vercel/geist-font
- Source Serif: https://github.com/adobe-fonts/source-serif
- Distribution: https://fonts.google.com/specimen/Geist and https://fonts.google.com/specimen/Source+Serif+4

Source Serif 4 is used for display headings; Geist for body and interface text.
